# 進学対策ガイド

大学受験・高校受験・中学受験・英検を対象に、学習参考書や小学生の授業補助教材を比較する静的サイトです。書籍の候補や学習ルート、出版社・公的機関の公開情報、Amazon.co.jpのタグ付き検索リンクを掲載します。特定商品の使用レビュー・合格実績を主張しません。

## 公開

`.github/workflows/pages.yml` の手動 GitHub Pages workflow を実行し、`confirm_publication=yes` を選択します。デプロイ対象は `site/` です。

## ページ

- `site/index.html` — 進学対策シリーズのトップ
- `site/university-books/` — 大学受験の参考書比較
- `site/highschool-entrance/` — 高校受験の参考書比較
- `site/elementary-entrance/` — 保護者向けの小学生授業補助・中学受験教材比較
- `site/eiken-prep/` — 英検5級〜1級の級・目的別教材比較（6級・7級は導入延期情報を明記）
- `site/kanji-kentei/` — 小学生から高校生までの漢検級別教材比較

各教材ページにAmazonアソシエイト開示、出版社出典、商品検索リンクを記載しています。リンク先で版・ISBN・対象学年・価格を確認してください。
